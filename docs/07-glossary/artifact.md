# Artifact

## Definition

An Artifact is any governed engineering document or output — a Specification, Discovery, ADR, Work Order, Implementation Report, Case Study, or similar — that participates in AAOE's traceability chain. Context Engineering treats artifacts, including context itself, as first-class engineering assets.

## Why It Matters

Engineering knowledge in AAOE moves between stages as artifacts, not as tribal knowledge held only in someone's memory. Every governed artifact should identify its upstream authority, which is what makes the Traceability Model possible in practice.
