# Architecture Review

## Definition

Architecture Review is the stage of the Engineering Lifecycle at which completed work is evaluated against approved architectural intent before it can become part of AAOE's canonical knowledge. It evaluates scope compliance, architectural fidelity, deliverables, constraints, and specification compliance — not implementation style, tool choice, or IDE configuration.

## Why It Matters

Architecture Review protects architectural integrity while leaving the Implementation Agent free to determine how intent is carried out. It produces one of three outcomes — Approved, Approved with Recommendations, or Revision Required — and it is explicitly a governance activity, not an implementation activity.
