# Traceability

## Definition

Traceability is the evidence chain that connects observations to engineering outcomes: Observation → Discovery → Architectural Decision → Specification → Work Order → Implementation → Implementation Report → Architecture Review → Release. Every governed artifact identifies its upstream authority, and historical references are never rewritten.

## Why It Matters

Traceability lets any accepted artifact be explained — why it exists, what evidence supports it, and what authority approved it. Without it, artifacts can only be evaluated in isolation; with it, they can be evaluated against the reasoning that actually produced them. Missing traceability is treated as a governance gap even when an artifact is otherwise correct.
