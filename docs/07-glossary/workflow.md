# Workflow

## Definition

**Note:** "Workflow" is used consistently as a recurring section (typically "Engineering Workflow") across nearly every AAOE Standard and Guide, but is not independently defined as a standalone term separate from the Engineering Lifecycle. This entry is a candidate for future refinement.

Provisionally: a Workflow is the preferred ordered sequence of engineering stages for a given practice — for example, Requirements → Specifications → Architecture Review → Implementation → Validation for Specification-Driven Development.

## Why It Matters

Nearly every AAOE Standard defines its own preferred workflow, showing the same underlying pattern — architecture before implementation — applied to a specific practice. Naming the workflow explicitly makes that pattern checkable rather than assumed.
