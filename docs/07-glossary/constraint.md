# Constraint

## Definition

A Constraint is an explicit boundary on how a Work Order's objective may be achieved. Constraints are one of the canonical sections of a Work Order, alongside Objective, Context, and Scope, and they must be stated explicitly rather than left for the Implementation Agent to infer.

## Why It Matters

Architecture is never inferred: an Implementation Agent that has to guess at constraints will guess wrong some of the time, and by the time that surfaces, implementation has already gone in the wrong direction. Explicit constraints keep implementation within the boundaries architecture actually intended.
