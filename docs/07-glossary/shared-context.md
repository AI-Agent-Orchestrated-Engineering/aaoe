# Shared Context

## Definition

Shared Context is the common engineering context — Specifications, Standards, ADRs, Work Orders, Architecture Reviews, and Implementation Reports — that multiple humans and AI agents draw on to collaborate consistently. It is the shared workspace collaboration happens inside.

## Why It Matters

Collaboration quality depends directly on context quality. Without shared context, specialization among multiple engineers or AI agents stops being a strength and becomes fragmentation, with each participant working from a different, partial picture of the same system.
