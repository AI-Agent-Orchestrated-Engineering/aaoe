# Architecture Decision Records

Architecture Decision Records (ADRs) preserve the rationale for significant
AAOE governance and architecture decisions. Each ADR is immutable in intent:
later decisions may supersede an earlier ADR, but do not rewrite its original
rationale.

## Statuses

- **Proposed** — awaiting maintainer review.
- **Accepted** — approved and in effect.
- **Superseded** — replaced by a later ADR.
- **Deprecated** — retained for history but no longer recommended.
